# مادر — هسته مستقل

وب‌سایت React + Vite با اتصال مستقیم مرورگر به Supabase و بدون SDK یا توابع پلتفرم واسط.

## اجرا
1. Node.js نسخه 20 یا جدیدتر نصب کنید.
2. `npm install`
3. فایل `.env.example` را به `.env.local` کپی کنید.
4. مقدارهای عمومی پروژه Supabase را در `.env.local` وارد کنید.
5. `npm run dev`

## ساخت نسخه انتشار
`npm run build` سپس پوشه `dist` را روی میزبان استاتیک منتشر کنید.

## اتصال داده
- کلاینت از `@supabase/supabase-js` استفاده می‌کند.
- فقط کلید عمومی/anon در مرورگر مجاز است؛ هرگز service_role یا رمز محرمانه را در متغیرهای VITE قرار ندهید.
- این نسخه هیچ SQL، جدول، کاربر، سیاست RLS یا تنظیمی را در پایگاه داده تغییر نمی‌دهد.
- جدول‌های مورد انتظار شامل apps و support_messages و سایر جدول‌های محتوایی هستند.
- خواندن عمومی فقط به ردیف‌های منتشرشده محدود شده است. دسترسی نوشتن باید با RLS در سمت پایگاه داده محدود شود.
- پنل فعلی ورود امن و نمای اولیه مدیریتی دارد؛ عملیات حساس مدیریت تا بررسی سیاست‌های RLS فعال نمی‌شود.

## حالت پیش‌نمایش
بدون متغیرهای Supabase، صفحه اصلی با داده نمونه اجرا می‌شود. فرم‌های نیازمند ذخیره‌سازی اتصال واقعی می‌خواهند.

## امنیت
کلید service_role فقط باید در محیط سرور امن نگهداری شود. احراز هویت با Supabase Auth انجام می‌شود و هیچ کد مخفی سازنده‌ای در کد فرانت‌اند قرار ندارد.
